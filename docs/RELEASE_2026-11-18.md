# 18 November 2026 source preview

**Tag:** `v2026.11.18-preview.1`. Start with the [tester guide](TESTING_2026-11-18.md). It gives separate checks for a laptop, an installed Pi camera and the PX4/Gazebo lab. The previous preview is [16 November](RELEASE_2026-11-16.md).

## What changed

| Area | What a tester can now observe |
|---|---|
| OAK depth and 3D | The expanded inspector shows RGB and colour depth from the same capture. Closing it restores RGB-only. Depth views show distinct displayed pairs per second and an age bound when available. Frozen pairs expire. The 3D viewer has camera axes, a stable viewing centre and a one-metre reference grid. |
| Calibration | Four A4 targets have matching GUI presets. Measured placements record mount revision, tape confirmation and optional uncertainty. The export includes capture images, a per-capture CSV and a separate setup/validation summary with missing readings counted. [Operator guide](../hosts/pi5/demo/chennai/OPERATOR.md) · [Printable targets](../hosts/pi5/demo/chennai/oak-targets-a4.pdf). |
| Operator controls | The page identifies the tab holding the simulator lease, the last flight request from this tab, and PX4's reported mode, arming, ground contact and altitude. Stale aircraft telemetry is shown as unknown. The QGC history view reports recorded link events where available. |
| FC bridge | Physical endpoints are receive-only. In simulator bridge tests, disarm, Offboard exit and a sender stall revoke authority. An old request cannot resume the stream after those events. |

## What was tested

**Public checkout.** The release workstation passed 1,293 Python tests and 197 page tests. The short Python command in the tester guide also passed all 24 checks in a newly created environment. The PDF contains four landscape A4 pages. Verify your own printer scale before using it for any measurement.

```sh
# Extended suite for a prepared project test environment
PYTHONPATH=services/garuda-follow:hosts/pc:hosts/pi5:hosts/pi5/oak:bench python -m pytest -q services/garuda-follow/tests hosts/pc hosts/pi5 bench tests/release
node --test hosts/pi5/demo/*.test.js
```

**Reference Pi.** The publishing team verified the upstream `f1cd58f` deployment on its OAK-D Pro / Pi 5 / Hailo station. Four served JavaScript files and two served handouts matched that deployment. Camera frames advanced through the update. The installed bridge refused a physical transmit request before opening a socket. A fresh observer tab showed the camera label and the simulator reporting disarmed and on ground. The public engineering handout has GitHub checkout instructions. The matching public receipt requires that edition of the handout.

**Depth display.** On the reference fan-cooled bench, each of five viewing modes ran twice for 30 seconds. Under that setup the detector processed about 13.4–14.9 frames/s. Fine 3D displayed about 1.9 distinct pairs/s and Full about 1.0. These counters describe different workloads. The comparison supplies neither a sustained thermal rating nor a distance accuracy figure.

**PX4 with Gazebo.** Chrome used an empty synthetic camera scene on the page and live laptop SITL telemetry. Takeoff with no selected target stayed in Hold. A second session could not renew the controlling lease. Reload became an observer. Simulated takeover to Loiter stopped lab setpoint publication. A Land request ended with fresh disarmed and grounded telemetry. The simulator flight log from one run recorded a 1.286 m rise and a maximum 0.075 m horizontal displacement from its first local-position sample. In a separate grounded test, interrupting local SITL telemetry made aircraft state unknown and recovery left the vehicle disarmed. No airborne person tracking was exercised in this rehearsal.

## What still needs local validation

- Test the actual camera, mount, print scale, near/middle/far tape references and depth coverage on each receiving station. A completed candidate lens fit does not apply calibration automatically.
- The team separately reports a physical Pi-to-FC Ethernet test with Offboard entry and motor spin with propellers removed. The sender revision and FC log from that test were not part of this release. Physical GUI takeoff, airborne target loss, pilot takeover and orbit remain unqualified.
- The release consists of tagged source, documentation and the printable PDF. The older binary installer has a separate version. A clean installation of the complete Pi/Hailo/PX4 stack and the separate settled-handover altitude-band rehearsal remain open.

The public update brings forward the development changes from `d326644` through `f1cd58f` on top of public commit `a011801`. Private coordination, calibration sessions, credentials, new model binaries and per-station flight logs are excluded.
