# 16 November 2026 — camera and flight-lab source preview

Read [What’s new](WHATS_NEW_2026-11.md) for all 13 features, their controls, status and limits.
This preview updates source and documentation; it is not a product or real-flight release.

## Upgrade and first use

1. Keep your currently deployed revision and service settings for rollback. Fetch/pull `main`
   into a clean development checkout; do not overwrite a running demo from an unreviewed tree.
2. Read [DEMO_USER_GUIDE.md](DEMO_USER_GUIDE.md) and [UNIFIED_CAMERA_PROFILES.md](UNIFIED_CAMERA_PROFILES.md).
   Choose OAK, CM3 or USB settings for your hardware; obtain compatible Hailo models separately.
3. Start with the camera page in preview/shadow mode, verify capture, detection, person selection,
   identity loss and restart behavior. The browser face controls remain visible; named-face behavior
   has unit tests but has not been validated with a real face in this release.
4. Follow [the PC guide](../hosts/pc/README.md) for isolated PX4/Gazebo setup. Start with a grounded
   simulator. Use [flight test modes](FLIGHT_TEST_MODES.md) to choose bounded live-camera yaw or
   simulated-camera closed loop. Select a person and explicitly request Follow.
5. Read [FC_BRIDGE.md](FC_BRIDGE.md) before inspecting the separate bridge. The unified UI's
   Real vehicle option is unavailable; no real FC deployment is included in this publication.

## Validation boundaries

- Previous Pi checks demonstrated OAK capture/detection, host stereo previews and the integrated
  page. USB had a short bench check; CM3 needs a first run by a team with that hardware.
- Existing Gazebo/PX4 and bridge rehearsals are simulator evidence only. Changes to pause/recovery
  have offline regression coverage; the revised airborne settled-handover test with a ±0.20 m
  altitude acceptance band has **not been run**. Earlier zero-vertical-speed height loss remains open.
- The new bounded bench trial is yaw-only and requests Hold at 3 seconds or 30° accumulated turn.
  Its actual main/HTTP/tick/setpoint path was tested with ROS transport stubbed. Installed grounded
  checks do not constitute airborne evidence. Stopping dynamics can overshoot the threshold.
- Stereo tape calibration, multi-person identity crossings, real-face confirmation, a full
  carry-around, sustained cooling, fresh-machine installation and physical FC/flight validation
  remain open. Model licensing notices still apply; publication is not product clearance.
- No new live deployment or simulator flight was performed to publish this repository.
